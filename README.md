# [Microsoft Ignite 2026](https://ignite.microsoft.com)

## 🔥PREL42: Build with Microsoft IQ: A hands-on workshop for context-aware AI

### Session description

AI applications need more than powerful models. They need the right context to reason, decide, and act effectively. In this workshop, you'll learn how Microsoft IQ brings enterprise and real-world context into AI applications through a combination of expert-led instruction and hands-on Python labs. You'll learn how to retrieve enterprise knowledge with Foundry IQ, access workplace context with Work IQ, work with business data through Fabric IQ, and incorporate real-time web sources with Web IQ.

### 🚀 Getting started

#### In a guided session

If you're following along during a live session:

1. Sign in to the lab environment provided for the session
2. Follow the lab instructions in the Skillable sidebar

#### On your own

If you're learning at your own pace:

1. Clone this repository
2. Deploy the Azure resources to your own subscription by following
   [Deploy to your own Azure subscription](docs/deploy-yourself.md)
3. Follow the [lab instructions](instructions/skillable.md), running the
   [notebooks](notebooks/) and the [agents](src/README.md)

### 🎯 Learning outcomes

By the end of this session, you will be able to:

- Call Web IQ, Fabric IQ, and Work IQ endpoints from Python and use each IQ's MCP server from the GitHub Copilot app
- Build Foundry IQ knowledge bases that combine indexed documents, Fabric data, Microsoft 365 email, and web content as knowledge sources for agentic retrieval
- Build Microsoft Agent Framework agents that use Foundry IQ and Work IQ through MCP, and run them using Foundry hosted agents
