# Attendee instructions

Step-by-step instructions for the hosted Skillable lab are in [skillable.md](skillable.md). Paste the whole file into Skillable; each `===` starts a new sidebar page.

## Skillable formatting

Use Skillable's native `> [!Alert]` blocks for warnings, not plain bold text or warning emoji. Prefix every continuation line, including blank lines and numbered troubleshooting steps, with `>`. Indent the whole block when it belongs to a numbered step. See [Skillable's Markdown syntax](https://docs.skillable.com/docs/creating-instructions-with-markdown-syntax#special-formatting).

Images in pasted instructions must use accessible HTTPS URLs. Repository-relative image paths do not carry over when Markdown is pasted into Skillable, and this private repository's images are not anonymously accessible. The Temporary Access Pass example in `skillable.md` uses a public Microsoft Learn image. To use the lab-specific screenshot instead, upload [windows-auth-login.png](../img/windows-auth-login.png) through the Skillable instructions editor and replace both example image URLs with the reference generated by Skillable. Do not publish private screenshots or embed GitHub access tokens in image URLs.

The repository's sign-in guidance is newer than the previously exported Skillable warnings. Preserve the repository guidance when updating Skillable; do not restore the resolved authentication-failure warnings.

## Self-deployment

To run the lab in your own Azure subscription instead, follow [Deploy to your own Azure subscription](../docs/deploy-yourself.md).
